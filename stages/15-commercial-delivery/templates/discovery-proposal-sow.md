# 付费 Discovery Proposal / SOW

**文档状态：** Draft / For Review / Executed　**版本：**　**有效期：**

## 1. 背景与待验证问题

描述客户当前决策和流程证据。所有未验证的数量、成本和改善预期用“待测量”标出。

## 2. 目标与 Non-goals

- 要交付的决策结果：
- In scope 用户、流程、产品、地区、语言、数据源：
- Out of scope；尤其列出自动发送、约束性建议/报价、生产部署：

## 3. 工作包与交付物

| 工作包 | 活动 | 交付物 | 客户参与 | 完成定义 |
|---|---|---|---|---|
| 流程与基线 | 访谈、跟岗、取样 | Problem Brief、As-Is、指标口径 | | |
| 数据与知识 | Inventory、权威源、授权缺口 | Data/Knowledge Map | | |
| 方案与风险 | 架构、AI 边界、安全预检 | Pilot Design、Risk Register | | |
| 商业决策 | 资源、报价、收益假设 | Pilot SOW、Go/No-go 建议 | | |

## 4. 计划与治理

启动/结束日期、会议、双方负责人、决定机制、每周状态、升级路径。客户延迟提供依赖时如何调整排期。

## 5. 验收

指定验收人、提交方式、评审期、具体接受标准、拒绝时必须说明的差异、修复期、视为验收规则（如适用且经法务批准）。不使用“客户满意”作为唯一标准。

## 6. 费用与付款

固定费用、税、币种、发票、付款期限、费用/差旅、里程碑百分比。合同生效和开工授权必须可验证。

## 7. 客户责任

提供人员、日历、访问、授权数据、资料 Owner、采购/安全反馈和验收。未履行时的排期/费用影响。

## 8. 数据、安全与知识产权

引用 MSA/DPA/安全附件；列数据用途、字段、环境、区域、保留/删除、子处理者、模型训练政策和事故通知。不要在此模板自行决定法律条款。

## 9. Change Control、停止与终止

新增范围怎样估价和批准；哪些发现会 Stop；终止时已完成工作、费用、数据删除和资产返还如何处理。
