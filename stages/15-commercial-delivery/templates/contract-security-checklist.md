# 合同、采购、数据与安全尽调清单

> 此清单用于路由问题和留证，不替代法务、安全、税务或财务审阅。

| 类别 | 需敲定事项 | Owner | Gate | 状态/证据 |
|---|---|---|---|---|
| 采购 | 供应商注册、PO、币种、税、发票、付款期限 | Procurement/Finance | B | |
| 合同 | MSA、SOW 优先级、责任限制、赔偿、终止、争议法域 | Legal | B/E | |
| 验收 | 验收人、标准、评审期、修复、拒绝和视为验收 | Business/Legal | B/D/F | |
| 知识产权 | 背景 IP、交付物、配置、反馈、开源和第三方 | Legal/Product | B/E | |
| 数据 | 控制者/处理者、目的、字段、区域、保留、删除、DSR | Data/Privacy | C/E | |
| 模型 | 提供商、训练使用、日志、区域、保留、退出机制 | Security/Privacy | C/E | |
| 安全 | SSO/MFA、RBAC、租户隔离、加密、密钥、漏洞、日志 | Security | C/E | |
| 集成 | 只读/写入、凭据、限流、变更、sandbox、撤销 | IT/System Owner | C/E | |
| 事故 | 严重度、响应、通知、联络、取证、复盘 | Operations/Legal | C/E | |
| SLA | 服务时间、可用性、支持渠道、响应/恢复、排除项 | Operations | E | |
| 合规 | 适用法规、客户政策、审计权、证明材料 | Legal/Security | C/E | |
| 退出 | 数据导出/删除、访问撤销、资产返还、过渡协助 | Joint | F | |

## 必须阻断开工的红线

- 没有合同或等效书面开工授权；
- 没有真实数据用途/字段授权却要求导入数据；
- 客户要求的写入或自动动作不在 SOW 和安全批准中；
- 验收人、范围、费用或付款触发无法确定；
- 团队无法履行已写入的安全、SLA 或事故承诺。
