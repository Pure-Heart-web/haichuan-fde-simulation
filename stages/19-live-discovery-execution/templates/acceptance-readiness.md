# Discovery Acceptance Readiness

## Contract and scope

- [ ] 当前 SOW/变更版本与合同系统一致
- [ ] 六项交付物均有 Owner、标准、证据和稳定 artifact reference
- [ ] 未批准范围没有混入交付结果
- [ ] 客户依赖全部关闭，延期和影响已记录

## Evidence and baseline

- [ ] 客户事实有来源与客户确认
- [ ] FDE 推断和开放假设均明确标识
- [ ] 开放假设只进入限制或下一步测试，没有写成结果
- [ ] 五项基线的周期、分母、来源和版本已冻结并双签

## Governance and economics

- [ ] RAID、决定和 Change Request 完整
- [ ] 实际工时、加载成本、客户等待和返工已登记
- [ ] Business Case 分开显示已测量事实、估计和敏感性
- [ ] 数据、安全、IP、保留和删除决定有权威引用

## Handoff

- [ ] 客户 Acceptance Owner 收到一致版本的六项交付物
- [ ] 接受、附条件接受或拒绝的期限与方式已约定
- [ ] Steering Meeting 明确 Stop / Iterate / Pilot 三种决定
- [ ] Pilot 仍需独立 SOW、授权、环境和数据 Gate
