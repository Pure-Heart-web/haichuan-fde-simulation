# ADR-005：产品推荐不等于文档检索

**状态：教学实现采用。** 决策范围仅限海川模拟标准离心泵；2026-09-20。

当询盘为 85 m³/h、38 m、海水时，产品说明中的相似词可能同时命中多个型号。文本相关性不能证明流量和扬程区间满足要求，也不能自动执行“海水排除铸铁”的约束。因而推荐链分四层：确定性硬筛 → 有来源的领域规则 → 透明代理排序 → 人工判断。文档检索将来可帮助销售找到说明或解释，但不能覆盖硬筛和排除规则。

Stage 3 权威技术表与 Stage 5 示例区间不一致时采用 Stage 3 登记的来源。规则 `R-003` 仅是候选，当前排序只用区间中心距离代理，并标记“靠近范围边缘”；这不是泵性能曲线，也不能宣称效率、安全余量或最终型号。所有结果均为 provisional，销售或工程师需复核。特殊介质、≥80°C、无候选、低置信度、非标电源和排序接近等进入升级路径。未来若取得签核性能曲线，可单独实现曲线计算与版本化测试，而非修改文字检索提示词来暗中改变工程约束。
