# Acceptance Remediation Register

| Condition ID | Deliverable | Contract criterion | Observed gap | Classification | Owner | Due | Closure evidence | Re-reviewer | Status |
|---|---|---|---|---|---|---|---|---|---|
| | | | | defect / dependency / new_scope | | | | | open |

规则：

- `defect`：已约定标准没有满足，由交付团队整改；
- `dependency`：客户或第三方依赖导致，按合同机制处理日期和责任；
- `new_scope`：合同外要求，进入 Change Request、费用和排期评估；
- Owner 不能是唯一复验人；
- Artifact 变化后重新计算摘要并取得新签核。
