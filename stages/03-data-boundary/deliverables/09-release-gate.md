# Release Gate V0 与 Stage 3 退出

## Pilot 门槛假设

| 门槛 | 候选值 | 前提/状态 |
|---|---|---|
| 关键字段准确率 | ≥95% | 字段级真值由人工标注；尚无模型预测 |
| 关键信息缺口召回率 | 待实测后确定 | 漏掉介质/应用可能高风险，先建错误集 |
| Top-3 候选覆盖率 | ≥90% | 需要经工程师批准的候选真值；当前无法计算 |
| Critical Rule Violation | 0 | 逐规则反例测试；当前只有模拟规则 |
| 正式产品建议复核率 | 100% | 必须有 ReviewTask 审核日志 |
| 未审核自动发送 | 0 | V1 发送由人执行 |

这些数值来自原始 Stage 3 文档，是**Pilot 假设**，非达成结果或行业标准。真实投放前另需错误成本、复核负担、分人群和分产品线表现；失败时暂停对应自动辅助能力、升级人工，并回查数据、标签与规则版本。

## 设计阶段退出

本仓库提供 Inventory、分级、权威来源表、Data/Context/Knowledge/Rules/Tacit 分离、隐性知识处理流程、AI Boundary、架构、数据契约、Golden Dataset V0、Release Gate V0。运行审计后状态应为 `DESIGN_READY_FOR_REVIEW`，仅表示这些设计资料和合成数据齐备。未完成的真实客户签阅、完整曲线、政策/证书来源、客户身份确认、正式价格权限及真实 Eval 都列入 [交接](10-stage-4-handoff.md)。
