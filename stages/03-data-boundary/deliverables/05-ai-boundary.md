# AI Boundary Matrix V1

| 任务 | 主要机制 | 输入/输出 | 人工边界与失败动作 |
|---|---|---|---|
| 邮件接收 | Adapter + Parser | `.eml` → WorkItem | 解析失败进人工队列 |
| 字段提取 | LLM 结构化输出 + Schema | WorkItem → InquiryRecord | 低置信或关键字段歧义交销售；保留原文位置 |
| 单位标准化 | 确定性代码 | 85 CMH → 85 m³/h | 不支持的单位标注未知，不猜测 |
| 缺失字段判断 | 经批准的 Domain Rules | InquiryRecord → 缺口清单 | 规则未知时升级工程师 |
| 客户身份与历史 | Entity Resolution + Order DB | 别名 → 候选订单 | 多个身份/订单时销售确认 |
| 产品硬过滤 | 技术产品数据库 | 工况 → 候选集合 | 冲突字段隔离；缺曲线不称最终适用 |
| 材料与温度约束 | 规则引擎 | 候选 → 警告/拦截 | 关键规则不可绕过，例外交陈工 |
| 候选排序 | 规则/代码，未来可评估统计方法 | 候选 → 排序 | 边缘工作点规则未验证，排序须审核 |
| FAQ 检索 | 版本受控搜索 + 可选 LLM 表述 | 已批准文档 → 引用 | 没有保修/认证权威文档则答“待确认” |
| 推荐说明 | LLM 基于候选和证据写解释 | Recommendation | 不可编造型号；正式建议人审 |
| 最终型号确认 | Human | 推荐 → 决定 | 陈工或授权销售确认；高风险陈工审核 |
| 报价/特价 | V1 范围外 | 无模型输入 | 经理权限与审批系统 |
| 回复草稿 | LLM | 已确认信息 → Draft | 销售审核后才能发送 |
| 发送 | Human | 审核后草稿 → 邮件 | V1 无自动发送 |

矩阵是设计分工，尚无实际生产连接器、LLM 或 UI。每个结果应含来源 ID、版本、风险和待确认字段，以便 ReviewTask 追溯。
