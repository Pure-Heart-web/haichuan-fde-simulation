# Stage 4 · Build Sprint 1 交接

**首个可实施切片。** 从授权的测试邮件读入 WorkItem，提取关键字段并规范单位，形成带原文引用的 InquiryRecord，经人审 UI 显示与修正。取真实脱敏的 20 条询盘做离线评估，记录错误。产品推荐、正式报价和自动发信暂不进入第一 Sprint。

| 角色 | 交接任务 |
|---|---|
| Lead FDE | 契约与架构审查、规则访谈、评估定义、PR Review、客户 Owner 回读 |
| Engineer A | 邮件解析、抽取接口、Schema 校验、LLM Gateway 的可替换边界 |
| Engineer B | Review UI、修正记录和人工审核流程 |
| Engineer C | 单位规范化、数据质量、身份/订单资料准备 |

**进入开发前的具体阻塞。** 获得数据使用授权；技术部确认规则版本、适用范围和曲线；销售运营确认客户身份、订单关联；定义真实标注规则与审核人；IT 确认测试环境和访问权限。缺任一关键项时，可开发脱敏离线切片，但不得称生产就绪。

**建议 Issues。** 1) WorkItem Schema 与 `.eml` 解析错误队列；2) 字段级抽取与证据位置；3) 单位转换和异常输入；4) InquiryRecord 校验；5) Review UI 与审核日志；6) 20 条真实样本标注与离线评估；7) 数据权限和脱敏验证。每项需包含输入输出契约、示例、失败路径和人工验收条件。
