# 数据分级与访问边界

| 分级 | 演练示例 | V1 使用约束 |
|---|---|---|
| Public | 对外目录摘录 | 引用版本与有效性；过期目录不作为技术参数权威 |
| Internal | 技术表、内部 FAQ | 只取已批准字段，按角色访问 |
| Confidential | 询盘、回复、订单、技术聊天、标准价格 | 脱敏和最小权限；标准价格 V1 不进入生成上下文 |
| Highly Sensitive | 客户特价 | 完全隔离于 V1 模型上下文，经理审批 |

演练中的 `.example` 域名、`SIM` 币种和价格只是虚构占位。真实资料接入前由数据 Owner 确认脱敏、保留期限、访问角色和第三方处理范围。审计代码强制 `SRC-DISC` 为 `Highly Sensitive` 且 `model_context=prohibited`，并检查所有高敏感来源均为禁止状态。权限检查不能只写在提示词中。
