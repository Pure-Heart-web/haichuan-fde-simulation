# 参考事故复盘：Outbox 持续 503

性质：合成故障注入；真实客户影响为 0。

系统在三次本机 Mock 投递失败后把消息置为 `dead`，关联案例置为 `delivery_failed`，并创建 `outbox_dead_letter` 事故。审核和 Release Manager 批准记录保留，稳定 Idempotency-Key 未变化，没有绕过 Outbox，也没有改走真实通道。

根因是测试计划配置的持续不可用；系统按设计停止重试。长期动作不是提高无限重试次数，而是补充目标系统状态查询、人工重放批准、Dead Letter 告警和恢复后对账。本演练只能证明控制路径存在，不能证明真实告警时延或值班响应能力。
