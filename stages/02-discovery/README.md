# Stage 2 · Discovery 实战与问题建模

原始材料：[Stage 2 文档](source/original-stage-02.md)。本阶段把一封询盘的演示和三方访谈整理为可追溯的 Problem Brief、As-Is Workflow、Bottleneck Map、Decision Map、MVP Candidate 与待办清单。所有人物、邮件与结论仍为模拟。

## 演练路线

1. 先看 [会议操作脚本](guides/facilitation.md)，扮演 Lead FDE；Engineer A 记录技术细节。
2. 用 [空白观察与决策模板](templates/observation-and-decisions.md) 独立整理 [会议原始记录](data/meeting-record.md)。
3. 对照 [交付物索引](deliverables/README.md)；核对每个事实、主张和未知的来源。
4. 使用 `python3 stage_pipeline.py stage2` 查看机器检查结果。检查结构与引用，不代替业务回读。

Stage 1 的 Q001–Q006 是独立练习样本；本阶段 Inquiry #017 是新场景。不能把 Stage 1 计时均值直接当作 #017 的实测时长。

## 交接边界

本阶段完成问题模型和候选 Pilot 范围；Data Inventory、权威来源、Golden Dataset、AI Boundary 和最终 Pilot Scope 在 Stage 3 检查后才能确认。原始 Stage 2 文档里的完成清单用 `[x]` 表示教学流程已写出，并非真实客户签字。
