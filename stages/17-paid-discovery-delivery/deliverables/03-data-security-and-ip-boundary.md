# Discovery Deliverable 03：数据、安全与 IP 决策包

## 数据边界

允许候选字段：事件/来源 ID、版本、时间、租户、案例 ID、主题、正文的授权最小片段、公司暂定标识和产品需求字段。银行账户、政府证件、私人联系方式、内部价格底线、未授权附件和其他租户数据不得入库或进入模型。

真实数据必须位于 Git 外客户数据面；凭据进入 Secret Manager；原文在进入持久层前做字段允许列表和脱敏。保留期、区域、模型提供商、日志字段、删除和撤权由真实 Data/Security Owner 书面批准。

## 安全 Gate

Shadow 前必须获得：客户数据授权、PostgreSQL RLS 运行证据、企业 OIDC、只读邮箱/CRM Sandbox、OTLP 后端脱敏验证、客户 UAT、值班和事故演练。Stage 14 的本地 Lab 只提供测试方法，不能代替这些外部证据。

## AI 与 IP 边界

输出是内部建议；产品、价格、认证、保修和对外邮件由授权人员负责。未知工况、证据冲突和高风险案例弃答/升级。客户原始数据归客户；共享 Core、客户 Adapter、规则、Prompt、评估集、反馈和脱敏经验的归属在正式 MSA/SOW 中决定。本教学包不作真实法律结论。
