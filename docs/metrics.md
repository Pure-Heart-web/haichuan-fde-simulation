# 指标口径

所有当前数值均来自 6 条合成观察案例，是教学样本统计。它们不能代表全天流量、季节分布或真实企业基线。

| 指标 | 口径 | 限制 |
|---|---|---|
| 销售主动处理时长 | 同一案例各销售步骤的专注工作分钟数之和 | 排除等待；人工计时需要避免重叠 |
| 首次回复耗时 | 首封有实质内容的回复时间减收到询盘时间，按自然分钟 | 不是工作时钟；不计算节假日，也不代表解决时长 |
| 样本技术升级比例 | 明确升级给工程师的案例数 / 有效观察案例数 | 当前是定向取样，不能外推公司比例 |
| 工程师投入 | 每个案例的实际主动投入合计 | 可与销售工作并行，不能简单加到回复耗时上 |
| 工程师每日咨询次数 | 完整工作日、唯一咨询事件去重计数 | 当前没有全量咨询日志，必须显示未知 |
| 复杂询盘主要耗时 | 复杂样本各步骤平均主动时长排序 | 分类在观察前确定，不能按最终耗时倒推复杂程度 |

简单：型号/关键参数清楚，且资料一致。复杂：参数缺失、客户历史歧义、资料版本冲突或需专家确认。分类规则为本案例教学定义，真实项目应与流程 Owner 对齐。

百分位使用线性插值（位置 `(n-1)*p`）；展示均值、中位数、P90 和样本数，小样本 P90 只用于学习计算。

## 经济价值测算方法（暂不填收益承诺）

销售每月释放工时 = 每日有效询盘量 × 适用比例 × 每单净节省分钟 × 月工作日 / 60。

工程师每月释放工时另行计算。净节省时间必须扣除复核、纠错和补录。工时价值需要分别乘对应角色的成本，再减去系统、维护、培训成本；释放产能不等于现金节省。首次回复与成交之间的关系目前没有因果证据，不计入本阶段收益。

当前缺少全量流量、适用比例、真实净节省和角色成本，因此 ROI 保持待验证。样本技术升级率不可直接代入全年收益。
