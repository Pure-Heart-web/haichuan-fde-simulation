# ADR-005 · 不把推断或默认值静默写入抽取事实

状态：采纳于 Stage 4 教学实现；真实生产仍需客户 Owner 签阅。

背景：原始 Sprint 叙事中，提示词 “Fill common industrial defaults where reasonable” 导致 `380V/60Hz` 被错误补成 50Hz。该事件是教学案例，不是本仓库实际线上事故。

决定：`InquiryRecord` 的事实字段只能来自明确邮件内容或经审核的附件，并携带原文证据。缺失值保持 `null`；业务推断、建议默认值须放在独立字段或后续建议层，标明来源。当前版本不实现默认值建议。单位换算属于确定性处理，保留原始单位证据。人工更正另存 Feedback Event，证据来源为 `human_review`。

理由：把默认值伪装成客户事实会污染评估、误导技术判断，并可能形成错误商业承诺。清楚分离事实、推断和默认值能让审核者追溯每一处值。

验证：`380V/60Hz` 必须保留 60Hz；未写频率的邮件必须为 `null`；负流量或证据位置不符应失败并进入审核。后续模型 Prompt 不允许“合理补全”事实字段。
